About TuneIt

TuneIt is a free, browser-based instrument tuner designed for musicians of all levels. No downloads, no sign-up — just open the page and start tuning.

How It Works

TuneIt uses your device's microphone and the Web Audio API to capture sound in real time. A mathematical technique called autocorrelation analyzes each audio frame to identify the fundamental frequency of the note you're playing, then displays it on a semicircular needle meter with cent-level accuracy.

Supported Instruments

Chromatic — any instrument, any key. Auto-detects the nearest semitone.
Guitar — E2 A2 D3 G3 B3 E4 (standard tuning)
Bass — E1 A1 D2 G2
Ukulele — G4 C4 E4 A4
Violin — G3 D4 A4 E5

Features

Auto string detection highlights the string you're playing in real time. You can also manually lock any string as a reference. Theme preference (light/dark) is saved locally in your browser.

Privacy

All audio processing happens entirely in your browser. Your microphone input is never transmitted to any server. See our for full details.
